# Mudd Cottage Herbhome

A modern static website for **Mudd Cottage Herbhome** — herbal teas, remedies, and wellness guidance rooted in tradition.

**Live site:** [muddcottage.netlify.app](https://muddcottage.netlify.app)

## About

Mudd Cottage Herbhome is a herbal wellness brand based in Aboh-Mbiase, Owerri, Imo State, Nigeria. The site showcases their services, shares educational blog content, and makes it easy for visitors to get in touch via WhatsApp or a contact form.

## Features

- 🌿 Nature-inspired green/cream color theme
- 📱 Fully responsive (mobile, tablet, desktop)
- 💬 WhatsApp integration throughout (floating button + contact links)
- ✨ Scroll animations (Intersection Observer API)
- 🎯 SEO meta tags on every page
- 📊 Animated counters on trust bar
- 🍔 Mobile hamburger navigation
- 📝 Blog managed through the Decap CMS admin panel (`/admin`) — markdown posts built into HTML on deploy

## Tech Stack

- **HTML/CSS/JS** — no frameworks
- **Decap CMS** — blog writing via `/admin` (Netlify Identity + Git Gateway)
- **Netlify** — auto-deploys on push to `main`; runs `node scripts/build-blog.js` on every deploy
- **GitHub** — version control

## Writing Blog Posts

See [BLOG-GUIDE.md](BLOG-GUIDE.md). Posts are markdown files in `blog/posts/`, written through the admin panel or by hand. On every deploy, `scripts/build-blog.js` regenerates `blog/posts.json` and one HTML page per post — never edit the generated files directly.

## File Structure

```
muddcottage/
├── index.html              # Homepage
├── about.html              # About page
├── services.html           # Services page
├── contact.html            # Contact page
├── blog.html               # Blog listing
├── videos.html             # Videos page
├── sitemap.xml             # SEO sitemap
├── css/
│   └── style.css           # Main stylesheet
├── js/
│   ├── main.js             # Animations, nav, form handling
│   └── blog.js             # Blog post rendering
├── blog/
│   ├── posts/              # Markdown source posts (edit these)
│   ├── posts.json          # Generated by scripts/build-blog.js
│   ├── template.html       # Build template for post pages
│   └── *.html              # Generated post pages
├── scripts/
│   └── build-blog.js       # Markdown → posts.json + HTML pages
├── images/                 # Site images and assets
├── admin/                  # Decap CMS (admin panel at /admin)
└── netlify.toml            # Netlify build config
```
